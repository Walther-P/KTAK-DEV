# 台灣測速執法資料快照

`enforcement-tw.json` 收錄 **1,895 筆**警政署「測速執法設置點」官方資料，來自 [政府資料開放平臺資料集 7320](https://data.gov.tw/dataset/7320)。原始 CSV 下载 URL 與 SHA-256 存於 JSON 的 `download`、`sourceSha256`，便於核對來源。授權為[政府資料開放授權條款第 1 版](https://data.gov.tw/license)，免費使用。

## 更新

需要 Node.js 20 以上。在 `geodeck` 目錄執行：

```sh
node scripts/import-enforcement.mjs
```

若官方服務暫時無法連線，也可先從資料集頁面的 CSV 下載連結取得原檔，再執行：

```sh
node scripts/import-enforcement.mjs /path/to/download.csv
```

匯入器只有在下載、UTF-8 解碼、CSV 欄位及有效點位檢查成功後才寫入快照。CSV 支援引號內逗號及換行；第二列中文欄位說明不視為點位。本次 1,896 個非空紀錄中，排除 1 個中文說明列，保留 1,895 筆，無座標不合範圍、缺地址或完全重複紀錄。每次更新的統計會寫入 `statistics`。

## 欄位語意與限制

- `fetchedAt` 是此次匯入時間（UTC）；使用本機 CSV 時，是匯入該檔的時間，並非可證實的原始下載時間。
- `lastUpdated` 一律為 `null`：CSV 沒有資料更新時間。資料集頁面的「詮釋資料更新時間」不當作設備或 CSV 更新時間。
- `directionText` 保留官方 `direct` 文字；不推定行車 heading，也不代表與目前行車方向相符。
- `speedLimit` 僅接受 1–130 的有效數字，其餘為 `null`。
- 座標須為有限數值且在經度 117–123、緯度 21–27 的台灣及離島概略範圍。此檢查不能證明每個設備的實際位置精度。
- 官方來源沒有逐列的設備功能分類欄位。因此本快照統一使用 `fixed-speed`，表示測速執法點；即使地址含「科技執法」，也不憑名稱推定功能。此來源並未逐筆保證僅有固定設備，UI 不應據此推定特定設備型式。
- 未納入闖紅燈、一般科技執法或區間測速起訖分類，也不宣稱此快照涵蓋全台全部執法設備。官方資料不定期更新，設備可能增設、停用或更動；實際道路標誌及主管機關公告優先。
- 來源可能已有行政區與地址的重複文字；`name` 保留官方資訊供查證。相同座標但不同方向的紀錄保留，ID 由座標、地址、拍攝方向及管轄警局雜湊產生，與列序無關。

下載與匯入在開發階段執行。瀏覽器使用版本庫內的靜態快照，不直接向政府服務發送使用者位置。
