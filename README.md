# KTAK V2.1 DEV5 — 核心修正版

依 Windows / iOS 實測修正：
- 自訂形狀移除自由手繪，只留方形／三角形／圓形。
- 地圖與戰術板：長按戰術圖樣後新增左上「＋」複製。
- Google 地圖縮放關閉 Leaflet zoom animation；縮放期間暫時收起戰術層，Google idle 後恢復。
- 地圖縮遠時戰術圖樣大幅縮小，全台尺度不再維持市區大小。
- 手槍與步槍圖示重畫為清楚的側面輪廓。
- 戰術板 SVG 補上 XML namespace，修正快速圖樣黑色文字方框。
- 格局定型真正鎖住門、樓梯；友軍／敵軍／快速戰術圖樣仍可移動。
- 快速簡報移到右側可收合，不再擋 iOS 聊天送出。
- 照片流程改單次解碼，移除原本重複解碼；完成後顯示解碼／壓縮／上傳各階段時間。
- 恢復既有房間時先顯示「正在恢復任務房間」，避免短暫誤顯加入畫面。

下一階段新增：
- Web Push 聊天通知＋預覽開關
- GPS 成員定位＋頭像／暱稱
- 房間期限延長
- 成員封鎖
- 正式版 Google API Key 輪替
