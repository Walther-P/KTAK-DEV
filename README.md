# KTAK V2.1 DEV5.1 — 行動操作修正版

本版針對 DEV5 實測剩餘問題：

- 快速簡報右側箭頭可直接上下拖曳；位置會記住。
- 點箭頭仍負責展開／收合；拖曳與點擊會自動區分。
- iOS 戰術板：選取模式下，單指拖曳空白畫布即可上下左右平移。
- 點到物件時仍操作物件；兩指仍負責 75%～500% 縮放；繪圖工具維持單指繪圖。
- Windows / iOS 照片實測證明慢點位於 Storage 上傳階段，不是解碼或 JPEG 壓縮。
- 戰術照片改為最長邊 1280px、起始 JPEG 0.72，並自動嘗試控制在約 320KB 內。
- 傳完照片新增顯示壓縮後大小與實際上傳 KB/s，方便下一步判定是否為 Windows/Chrome/網路路徑問題。

沒有新增 SQL。
DEV5 的直接加入、Google Maps 成本保護、地圖/戰術板核心修正全部保留。
